# Text to MD V2

一个简洁的本地优先文档排版工具：将纯文本或 Markdown 整理为结构化文档，在单独打开的可编辑预览中微调后导出。

## 已支持

- 本地规则自动识别标题、段落、列表、引用、代码块、分隔线、表格与数学块
- 试卷模式识别选择题、判断题、填空题、简答题、计算题、代码题及参考答案区
- 识别题号与 A–H 选项，按题型组织题目层级，并应用对应预览 / Word 样式
- Markdown 支持由 markdown-it 解析，扩展高亮、上标与下标
- 识别 `$...$` 与 `\(...\)` 行内公式，并使用 KaTeX 渲染
- Word 导出为可编辑的原生标题、段落、列表、代码块与表格；排版按 Word 阅读习惯适配
- 单栏文本输入；点击后打开可编辑文档预览
- 快速排版会将规范化后的 Markdown 回写到输入框；预览区手动编辑也会同步回输入框
- 九种风格：简洁、商务、学术、学习笔记、正式报告、现代文档、中文公文、Notion、GitHub
- 可实时调整字体、字号、各级标题粗细 / 对齐 / 段距、正文缩进与字间距、列表缩进、行距和页面设置
- 自定义风格保存在当前浏览器，可再次套用
- 连续阅读与 A4 / Letter 页面预览
- 导出 Markdown、DOCX、PNG；PDF 使用浏览器原生“打印为 PDF”。DOCX 中的标题、正文与列表均可继续编辑
- 自动本地保存、TXT / Markdown 导入与移动端布局

所有内容优先在浏览器本地处理。Word、PNG 和公式组件在使用时从网站随附文件按需加载；代码高亮在对应内容出现时按需加载。

题型分类使用本地规则完成，不会调用 AI 或上传文本。Markdown 解析及标记扩展随网页一起打包，运行时无需连接 CDN。Word 与网页预览使用不同排版引擎，因此分页和细节会按 Word 适配；导出内容为可编辑文本。

修改源码后先运行 `npm install`，再运行 `npm run build` 重新生成 `app.bundle.js`。页面使用此单文件脚本，请通过在线版本运行。

## 使用

打开 [在线版本](https://wujunxiang-cover.github.io/wjxwjywjy-cover/)，输入或导入内容即可自动识别；点击“预览文档”调整内容与风格，最后点击“导出”选择格式、文件名和保存方式。
