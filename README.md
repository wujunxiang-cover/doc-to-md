# Text to MD V2

一个本地优先的轻量文档排版工具：把原始文本或 Markdown 自动整理为结构化文档，在可编辑预览中调整版式后导出。

## 已支持

- 本地规则自动识别标题、段落、列表、引用、代码块、分隔线、表格与数学块
- 左侧原始文本 / Markdown 编辑，右侧可编辑文档预览
- 五种模板：简洁、商务、学术、Notion、GitHub
- 字体预设、独立字体、字号、行距、段距与页面模式设置
- 连续阅读与 A4 / Letter 页面预览
- 导出 Markdown、DOCX、PNG；PDF 使用浏览器原生“打印为 PDF”
- 自动本地保存、TXT / Markdown 导入与移动端编辑 / 预览切换

所有内容优先在浏览器本地处理。Word、PNG、公式和代码高亮所需组件仅在对应功能启用时按需加载。

## 使用

打开 [在线版本](https://wujunxiang-cover.github.io/wjxwjywjy-cover/)，输入或导入内容，点击“自动排版”，然后在右侧微调并导出。
