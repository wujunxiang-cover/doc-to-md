# Text to MD V2

一个简洁的本地优先文档排版工具：将纯文本或 Markdown 整理为结构化文档，在单独打开的可编辑预览中微调后导出。

## 已支持

- 本地规则自动识别标题、段落、列表、引用、代码块、分隔线、表格与数学块
- 单栏文本输入；点击后打开可编辑文档预览
- 五种模板：简洁、商务、学术、Notion、GitHub
- 字体预设、独立字体、字号、行距、段距与页面模式设置
- 连续阅读与 A4 / Letter 页面预览
- 导出 Markdown、DOCX、PNG；PDF 使用浏览器原生“打印为 PDF”
- 自动本地保存、TXT / Markdown 导入与移动端布局

所有内容优先在浏览器本地处理。Word、PNG、公式和代码高亮所需组件仅在对应功能启用时按需加载。

## 使用

打开 [在线版本](https://wujunxiang-cover.github.io/wjxwjywjy-cover/)，输入或导入内容，点击“自动排版”，再点“预览并修改”调整文档并导出。请通过在线版本运行，不要直接用浏览器打开本地 `index.html` 文件。
